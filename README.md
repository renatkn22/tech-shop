# 🛒 TechShop

**TechShop** — сучасний full-stack інтернет-магазин техніки, розроблений на React, Node.js, Express, Sequelize та PostgreSQL.

## ✨ Можливості

* 👤 Реєстрація та авторизація користувачів
* 🔐 JWT-аутентифікація
* 🛍️ Каталог товарів
* 🔎 Фільтрація за типом та брендом
* 📄 Детальна інформація про товар
* ⭐ Система рейтингів від 1 до 5
* 📊 Розрахунок середнього рейтингу
* 🛒 Кошик
* ⚙️ Адміністративна панель
* ➕ Додавання товарів
* ✏️ Редагування товарів
* 🗑️ Видалення товарів
* 📷 Завантаження зображень

## 🚀 Встановлення та запуск

### 1. Клонування репозиторію

```bash
git clone <repository-url>
cd TechShop
```

### 2. Встановлення залежностей Backend

Перейдіть до папки сервера:

```bash
cd server
```

Встановіть необхідні залежності:

```bash
npm install
```

### 3. Налаштування бази даних

Для роботи проєкту необхідно встановити **PostgreSQL** та створити базу даних.

Після цього створіть файл `.env` у папці `server` та вкажіть параметри підключення:

```env
DB_NAME=your_database
DB_USER=your_user
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5432

SECRET_KEY=your_secret_key
```

### 4. Запуск Backend

У папці `server` виконайте:

```bash
npm run dev
```

Після запуску сервер буде доступний на:

```text
http://localhost:5000
```

### 5. Встановлення залежностей Frontend

Відкрийте новий термінал та перейдіть до папки клієнта:

```bash
cd client
```

Встановіть залежності:

```bash
npm install
```

### 6. Запуск Frontend

Запустіть React-застосунок:

```bash
npm start
```

Після запуску сайт буде доступний у браузері за адресою:

```text
http://localhost:3000
```

## ⭐ Рейтинг товарів

Користувач може оцінити товар від **1 до 5 зірок**.

Якщо користувач уже залишав оцінку, нова оцінка замінює попередню.

Середній рейтинг розраховується автоматично:

```text
Середній рейтинг = сума оцінок / кількість оцінок
```

## 🛒 Кошик

Авторизований користувач може додавати товари до кошика та переглядати список вибраних товарів.

## ⚙️ Адміністративна панель

Адміністратор може:

* додавати товари;
* редагувати товари;
* видаляти товари;
* додавати характеристики;
* встановлювати ціну;
* завантажувати зображення;
* керувати типами та брендами товарів.

## 🔐 Безпека

Для авторизації використовується **JWT**.

Паролі користувачів зберігаються у захешованому вигляді за допомогою **bcrypt**.

Файл `.env` не повинен додаватися до GitHub, оскільки він може містити конфіденційні дані.
